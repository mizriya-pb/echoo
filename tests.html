ECHOO TESTS

Automated checks for voice commands, formulas, converters and the right panel.

How to run: keep this file next to index.html, start your project with Live Server (VS Code → right-click → Open with Live Server), then open http://127.0.0.1:5500/tests.html. The tests start on their own. Green = passed, red = failed.
It opens your calculator in a hidden frame, sends it phrases as if you had spoken them, and compares the answer. It does not use the microphone, does not touch your saved history or settings, and always uses fixed currency rates (USD 85, EUR 98, GBP 115) so results never change.
