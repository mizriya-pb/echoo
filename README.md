ECHOO – Scientific Voice Calculator

About

ECHOO is a web-based scientific calculator that allows users to perform calculations using voice commands as well as manual input. It combines a simple interface with scientific calculation features.

Features

- Voice-based and manual calculations
- Basic arithmetic and scientific operations
- Trigonometric calculations
- Mathematical formulas
- Binary conversion
- Percentage conversion 
- Currency conversion

Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Python
- Integration: APIs

Development Tools

- Visual Studio Code (VS Code)
- Git and GitHub
